# MiniProjeto_MarceloAllegri_V2
Mini projeto de analise exploratória  de dados aplicado ao varejo, aplicando conceitos de ETL (Extração, Transformação e Carga) e qualidade de dados.O trabalho envolveu a limpeza de registros inconsistentes, tratamento de valores nulos, ajuste de tipos de dados e extração de insights estatísticos.

Tecnologias Utilizadas
Linguagem: Python
Biblioteca principal: Pandas (manipulação e tratamento de dados)
Ambiente de execução: Google Colab

Após o tratamento dos dados, chegamos às seguintes conclusões:
Limpeza Estrutural: Foram identificados e removemos mais de 96 mil registros duplicados, garantindo a integridade do dataset.
Perfil do Cliente: A análise descritiva revelou que a média de filhos dos clientes é de 1, com o máximo observado de 4 filhos.
Comportamento por Gênero: O público feminino representa o maior volume de compras em todas as categorias de produtos analisadas.
Preferência de Produtos: As categorias com maior volume de vendas são Alimentos, Higiene e Limpeza, indicando um forte perfil de consumo voltado para itens essenciais.
